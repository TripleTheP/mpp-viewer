# Datenschutz / Privacy

[Deutsch](#deutsch) · [English](#english)

## Deutsch

MPP-Viewer ist ein Desktop-Programm, das vollständig auf dem eigenen Rechner läuft. Es gibt kein Benutzerkonto,
keinen Server und keinen Onlinedienst des Projekts.

**Keine Datenübertragung.** Das Programm überträgt keine Informationen an andere Systeme im Netzwerk, sofern dies
nicht ausdrücklich von der Benutzerin oder dem Benutzer bzw. der installierenden oder betreibenden Person veranlasst
wird. Es gibt keine Telemetrie, keine Absturzberichte, keine Update-Prüfung, keine Werbung und keine Tracker.
Dateien auf Netzlaufwerken liest das Programm über die normale Dateifreigabe des Betriebssystems, Ausdrucke gehen an
den gewählten Drucker.

**Projektdateien** werden nur gelesen und nur im Arbeitsspeicher verarbeitet. Sie werden nicht verändert, nicht
kopiert und nirgendwohin übertragen. Exportdateien (PDF, Excel, PNG, CSV) entstehen ausschließlich an dem Ort, den
die Benutzerin oder der Benutzer auswählt.

**Lokal gespeicherte Einstellungen.** Das Programm speichert in der Datei `settings.properties` die gewählte Sprache,
die Fensterposition und -größe, den zuletzt verwendeten Ordner sowie die Pfade der zuletzt geöffneten Dateien. Die Datei liegt unter
`%APPDATA%\MPP-Viewer` (Windows) bzw. `~/.config/mpp-viewer` (Linux), oder im Programmordner, wenn dort eine Datei
`portable.properties` liegt. Sie verlässt den Rechner nicht und kann jederzeit gelöscht werden. Darüber hinaus
speichert das Programm keine Daten dauerhaft.

**Downloads und Repository.** Quellcode und Downloads werden auf GitHub bereitgestellt. Für den Besuch der
GitHub-Seiten und das Herunterladen gilt die
[Datenschutzerklärung von GitHub](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
Das Projekt selbst erhebt dabei keine Daten.

**Kontakt.** Fragen zum Datenschutz bitte als [GitHub-Issue](https://github.com/TripleTheP/mpp-viewer/issues) stellen.

## English

MPP-Viewer is a desktop application that runs entirely on your own computer. The project operates no user
accounts, servers or online services.

**No data transfer.** This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it. There is no telemetry, no crash
reporting, no update check, no advertising and no tracking. Files on network drives are read through the operating
system's normal file sharing, and printouts are sent to the printer you choose.

**Project files** are only read and processed in memory. They are never modified, copied or transmitted. Export
files (PDF, Excel, PNG, CSV) are only written to the location you choose.

**Locally stored settings.** The program stores the selected language, the window position and size, the last used folder
and the paths of recently opened files in `settings.properties`. This file is located in `%APPDATA%\MPP-Viewer` (Windows) or
`~/.config/mpp-viewer` (Linux), or in the program folder if a file named `portable.properties` exists there. It never
leaves your computer and can be deleted at any time. The program stores no other data persistently.

**Downloads and repository.** Source code and downloads are hosted on GitHub. Visiting GitHub and downloading files
is subject to the
[GitHub General Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
The project itself does not collect any data in the process.

**Contact.** Please raise privacy questions as a [GitHub issue](https://github.com/TripleTheP/mpp-viewer/issues).
